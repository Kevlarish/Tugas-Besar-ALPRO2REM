## About The Project
## APLIKASI ABSENSI SISWA
Aplikasi ini berfungsi sebagai alat bantu untuk mengabsensi kehadiran siswa. 
User dapat menambahkan, mengubah, dan menghapus data absensi siswa jika dibutuhkan.


## CARA MENJALANKAN PROGRAM
- DOWNLOAD file executable bernama "absensi.exe"
- LALU RUN dengan CMD
